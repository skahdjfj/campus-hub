# Campus Hub

校园聚合 App —— 把课表、作业、日历和待办收进一个入口，让学生不用在四五个 App 之间来回切换。

## 简介

Campus Hub 是一个 Flutter 应用，围绕「今天要做什么」这条主线，把校园生活里最常用的四类信息聚合到一起：

- **课表**：按周次查看课程安排，支持单双周、连堂和调课。
- **作业**：按课程和截止日期组织任务，临近截止自动提醒。
- **日历**：月/周视图纵览课程、作业截止与个人日程。
- **待办**：轻量的清单管理，用于社团事务、考试复习等自由事项。

数据默认全部保存在本地 SQLite 数据库中，不依赖账号体系，离线可用。

## 功能特性

| 特性 | 说明 |
| --- | --- |
| 课表管理 | 周视图课表，支持自定义节次时间与学期周数 |
| 作业追踪 | 截止时间、所属课程、完成状态 |
| 日历整合 | 课表 + 作业 + 待办统一渲染到日历视图 |
| 待办清单 | 分组、勾选、优先级 |
| ICS 导入 | 导入教务系统或第三方日历导出的 `.ics` 文件，自动解析为课程/日程 |
| 手动录入 | 不依赖任何外部文件，逐条添加课程、作业和待办 |
| 本地存储 | 基于 SQLite，数据不出本机 |

## 技术栈

- **框架**：Flutter（Dart）
- **本地数据库**：SQLite（`sqflite`）
- **目标平台**：Android（包名 `com.campushub.app`），后续计划支持 iOS

## 数据存储

所有业务数据写入应用私有目录下的 SQLite 库，表结构规划如下：

| 表 | 用途 |
| --- | --- |
| `courses` | 课程基础信息（名称、教师、地点、颜色） |
| `course_sessions` | 具体上课时段（星期、节次、周次范围） |
| `assignments` | 作业与截止时间 |
| `todos` | 待办事项 |
| `events` | 从 ICS 导入或手动录入的日历事件 |

ICS 导入时会对事件去重，并保留原始 UID 以便重复导入时增量更新。
